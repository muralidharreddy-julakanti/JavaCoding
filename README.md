## 🎯 About

This repository contains Java programs designed to practice fundamental programming concepts, algorithms, and problem-solving skills. Each program is well-documented and includes examples of input/output for better understanding.

## 📚 Prerequisites

Before running these programs, make sure you have:

- **Java Development Kit (JDK)** version 8 or higher installed
- **Java Runtime Environment (JRE)** 
- A text editor or IDE (VS Code, IntelliJ IDEA, Eclipse, etc.)
- Basic understanding of Java programming concepts

### Check Java Installation
```bash
java --version
javac --version
```

## 💻 Programs Included

### 1. **EvenOdd.Java**
- **Description**: Determines whether a user-entered number is even or odd
- **Concepts**: Basic I/O, conditional statements, modulus operator
- **Input**: Integer number
- **Output**: Even or Odd classification

## 🚀 How to Run

### Method 1: Command Line

1. **Navigate to the project directory**
   ```bash
   cd JavaCoding
   ```

2. **Compile the Java program**
   ```bash
   javac EvenOdd.Java
   ```

3. **Run the compiled program**
   ```bash
   java EvenOdd
   ```

### Method 2: Using IDE
1. Open the project in your preferred Java IDE
2. Right-click on the Java file you want to run
3. Select "Run" or use the IDE's run button
